# Уроки редактуры кофейных статей («неверно → верно»)

Список уходит в каждый промпт `--site coffee`. После каждой вычитки пакета новые находки дописываются сюда строкой `- Неверно: … → Верно: …`. Уроки шаблона «Сергей и Зоя» сюда не переносятся.

- Неверно: «Редакция АудиоЛад» → Верно: «АудиоЛад Кофейни»
- Неверно: «для вашей точки», «на точке» → Верно: «для вашей кофейни», «в кофейне»
- Неверно: «владельцы кофеен часто…» (множественное, обобщение) → Верно: «если у вас кофейня…»
- Неверно: «James Hoffmann», «The World Atlas of Coffee» → Верно: «Джеймс Хоффманн», «Мировой атлас кофе»
- Неверно: «—» → Верно: «–»
- Неверно: «Анна, бариста из Казани, сказала…» → Верно: без выдуманных героев, имён и городов – сразу к практической теме
- Неверно: «чтобы гость не испытывал дискомфорта» → Верно: «чтобы гостю было уютно»
- Неверно: «по данным исследований, 70 % гостей…» (нет в брифе) → Верно: не упоминать цифру
- Неверно: «точка безубыточности» → Верно: «порог безубыточности», «выйти на безубыточность»
- Неверно: «Не приравнивайте пешеходный поток к покупателям.» → Верно: «Пешеходный поток и покупатели – разные величины: …» (объяснение вместо запрета)
- Неверно: «Не ставьте выдачу там, где…» → Верно: «Выдача работает свободнее всего чуть в стороне от кассы…»
- Неверно: «Проверьте… Уточните… Сравните…» подряд в абзаце → Верно: «Удобно заранее проверить…, потому что…» (повелительное – в шагах и чек-листе)
- Неверно: «Это не является экспертизой выпечки» (оговорка после цитаты) → Верно: «Этот список удобно взять за основу дегустации…» (полезный вывод)
- Неверно: «является», «при отсутствии», «соответствующий» → Верно: «это», «если нет», «подходящий»
- Неверно: шаг «Посчитайте расход», пункт чек-листа «Проверьте дату обжарки» → Верно: «Посчитать расход», «На каждой пачке есть дата обжарки.»
- Неверно: «Обновлено 30 октября 2026» в тексте или seoTitle «… в 2026 году» → Верно: даты только в разметке, seoTitle без года
- Неверно: ссылка с анкором «здесь» или «по ссылке» → Верно: естественные слова фразы, например «барную стойку», «бизнес-плане кофейни»
- Неверно: «по требованиям санитарных норм» → Верно: официальный документ словами, как в фактах брифа, например «по СанПиН …» с номером из факта
