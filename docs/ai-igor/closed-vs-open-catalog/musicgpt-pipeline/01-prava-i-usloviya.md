# Права и условия MusicGPT

Проверено 15.11.2026 (Europe/Moscow) по официальным страницам `musicgpt.com` и `docs.musicgpt.com`. Клоны `musicgpt.cc`, `musicgpt.studio` и одноимённые сторонние сайты не использовались. Уверенность указана явно. Где факта нет – написано «не подтверждено», а не додумано.

Правовая модель АудиоЛад Бизнес – из отчёта этапа 1 и регламента stage3 в [PR #1261](https://github.com/Audiolad/audiolad/pull/1261): в закрытый каталог идёт только музыка, которая нигде не публиковалась; тариф с коммерческими правами подтверждается на дату генерации; паспорт, исходник, SHA-256 и проверки отпечатков обязательны.

## 2. Коммерческие права и «владение»

### Что говорит договор (ToS, п. 3.1)

Дословно по смыслу официального текста от 01.01.2025:

- пользователи **платных планов** имеют **full commercial rights** на сгенерированный контент;
- файлы, публично доступные в Discover, royalty-free, и сервис предоставляет **неисключительное** коммерческое использование звуков и песен;
- пользуясь сервисом, пользователь предоставляет MusicGPT **бессрочную, безвозмездную, неисключительную лицензию** использовать, демонстрировать (showcase) и распространять (distribute) сгенерированную музыку для улучшения сервиса, маркетинга и обучения.

Для загруженных файлов (п. 3.2) сказано иначе: «You retain ownership of uploaded files…». Для **сгенерированной** музыки слова «you retain ownership» / «we assign all right, title and interest» в ToS **нет**. Есть только «full commercial rights» у платных планов.

**Уверенность высокая** в тексте условий. **Уверенность средняя/низкая**, что это равно уступке исключительных прав или «владению» в смысле российского ГК. Формулировка слабее, чем у Suno (см. раздел 6). Юристу нужно отдельно оценить, что именно даёт «full commercial rights» и не мешает ли лицензия сервису на showcase/distribute закрытому эксклюзивному каталогу.

### Что говорит сайт и документация API (это не договор)

- Документация API, страница Pricing, 15.11.2026: «All paid plans include commercial use…».
- FAQ на `musicgpt.com/pricing` (JSON-LD страницы, 15.11.2026): «On any paid plan, MusicGPT grants you unlimited, worldwide, restriction-free rights to use it in any way – including commercially. This includes songs you download from Discover.»
- Подсказка тарифа «Commercial use»: «Unlimited commercial usage of downloaded files.» / «Use your downloads anywhere».

Маркетинговые формулировки («restriction-free», «anywhere») шире, чем ToS, где у сервиса остаётся лицензия на демонстрацию, распространение и обучение, а треки из Discover неисключительны. При расхождении опираться нужно на ToS, а не на FAQ.

Публичное исполнение в заведениях, фоновая музыка, РАО и ВОИС в условиях MusicGPT **не упоминаются**. Вывод «можно играть в залах» из текста ToS прямо не следует – это уже толкование «full commercial rights» / «anywhere». **Уверенность низкая**, пока нет письменного ответа сервиса или заключения юриста.

## 3. Приватность, Discover и Stealth

Это критично для регламента: трек, который хоть раз был опубликован где-либо, в новый каталог Бизнеса не попадает.

| Факт | Источник | Уверенность |
|---|---|---|
| У веб-тарифов Plus, Pro и Ultra есть функция **Stealth creation**; у бесплатного тарифа её нет (крестик / галочки на `musicgpt.com/pricing`, 15.11.2026). | Публичная страница тарифов | Высокая |
| Официальная подсказка функции: «Your generations to not be published by default.» | Строка интерфейса официального сайта | Высокая как цитата UI; как юридическое обязательство – низкая (в ToS такого пункта нет) |
| Что именно считается «published», входит ли сюда Discover, страница по ссылке, CDN-адрес – в ToS и в API-документации **не определено**. | Поиск по ToS, Privacy, docs.musicgpt.com | Высокая в том, что определения нет |
| В официальном API (`POST /v2/MusicAI`, OpenAPI) параметров `stealth`, `private`, `discover=false` **нет**. | OpenAPI и страница Music AI V2, 15.11.2026 | Высокая |
| Даже приватная генерация по ToS остаётся под бессрочной лицензией сервиса на showcase, distribute, training. | ToS п. 3.1 | Высокая |
| Готовые файлы API отдаются ссылками на `cdn1.musicgpt.com`. Это не то же самое, что публикация в Discover, но адрес файла существует вне нашего архива. Срок хранения по changelog: MP3 – 90 дней, WAV – 7 дней (запись марта 2026). | Changelog, примеры webhook | Высокая относительно документации; фактическое поведение CDN не вызывалось |

**Вывод для конвейера.** Режим «не публиковать» на веб-тарифе, скорее всего, есть (Stealth, Plus и выше). Для API это **не подтверждено**. До первого платного вызова нужно письменное подтверждение MusicGPT (api@musicgpt.com), что API-генерации не попадают в Discover и не открываются без ключа, кроме временной CDN-ссылки. Пока этого нет, запускать платный пилот для закрытого каталога рано.

## 4. Ownership License (документ о правах)

На веб-тарифах Plus, Pro и Ultra есть строка **Download license** (у бесплатного – нет). Официальная подсказка: «A downloadable document issued by MusicGPT to proof that you have the rights of your generation.» В интерфейсе есть строки об успешном и неуспешном получении файла лицензии. Значит, **на сайте документ, похоже, формируется и скачивается**. Как именно он выглядит, кто в нём назван правообладателем и оператором (Ltd или LLC), распространяется ли он на API-генерации – **не подтверждено**: PDF в этой задаче не скачивался, публичного API для лицензии нет (см. матрицу).

Регламент требует не модифицировать PDF и сохранить его SHA-256. Если файла нет – в паспорте отметка «ожидает ручного получения», а не выдуманная лицензия.

Связь веб-кабинета и API-аккаунта официально не описана. Документация создания API-аккаунта: зайти на `musicgpt.com/api`, выбрать пакет, ввести платёжные данные, затем ключ в API Dashboard. Является ли это тем же аккаунтом, где кнопка Download license, – **не подтверждено**.

## 5. Что важно для закрытого каталога Бизнеса

Сильные стороны (по сравнению с «вообще без договора»):

- у платного тарифа прямо записаны коммерческие права;
- API-документация это повторяет для платных API-планов;
- исходный WAV по официальному API можно скачать и положить в архив.

Слабые места именно для эксклюзивного закрытого каталога:

- сервис оставляет себе бессрочную лицензию на демонстрацию, распространение и обучение;
- трек из Discover становится неисключительным для всех;
- приватность API-генераций не документирована;
- нет уступки «всех прав», в отличие от более прямой формулы Suno;
- условия могут измениться сразу после публикации новой редакции;
- публичное исполнение в залах прямо не названо.

Это не запрет использовать MusicGPT. Это причина не обещать клиентам «исключительные права без оговорок» и сначала закрыть пробелы письмом сервиса и заключением юриста.

## 6. Краткое сравнение с Suno

Источники Suno, проверены 15.11.2026: [Terms of Service](https://suno.com/terms) (Date of Last Revision: August 10, 2026; Effective Date: September 3, 2026); справка [Does Suno own the music I make?](https://help.suno.com/en/articles/2416769) (edited 7 January 2026); [What rights do I have with a paid subscription?](https://help.suno.com/en/articles/9601665) (edited 3 September 2026); [What is commercial use?](https://help.suno.com/en/articles/9601985) (edited 17 December 2025). Это совпадает с редакцией, уже разобранной в регламенте stage3.

| Тема | MusicGPT (ToS 01.01.2025 + сайт 15.11.2026) | Suno (ToS с 03.09.2026) |
|---|---|---|
| Оператор | MusicGPT Ltd, Сингапур | Suno Inc., США (Массачусетс) |
| Платный тариф и права | «Full commercial rights» у paid plans. Уступки ownership в ToS нет. | Pro / Premier: Suno **уступает** пользователю все свои права на Output, с оговорками ToS. Бесплатный тариф – только личное некоммерческое использование. |
| Охрана авторским правом | В ToS прямой оговорки нет. | Прямо: Suno не заявляет и не гарантирует, что в Output возникнет copyright. |
| Лицензия сервису | Бессрочная неисключительная на use, showcase, distribute (улучшение, маркетинг, обучение). | Широкая бессрочная лицензия на Content, включая Output: использование, воспроизведение, распространение, обучение моделей и показ другим пользователям в рамках сервиса. |
| Коммерческое использование | Формула широкая, залы не названы. FAQ обещает «anywhere», но это не ToS. | Коммерческое использование **только** для Output, полученного через разрешённый Download в лимите тарифа; вне официального канала скачивания – нельзя. Справка перечисляет дистрибуцию, кино, игры, самостоятельную продажу; залы тоже не названы. |
| Публичность | Discover делает трек неисключительным. Stealth на вебе: «не публикуется по умолчанию». Для API – не подтверждено. | Есть публичный форум; можно сменить настройки, чтобы генерации оставались приватными. |
| Документ-сертификат | На вебе – «Download license» (Plus и выше). Через API – не найдено. | Отдельный «Ownership License PDF» в этом сравнении не разбирался; в регламенте уже учтены условия Pro / Premier. |

Для конвейера Бизнеса оба сервиса требуют: платный тариф на дату генерации, сохранение условий и чека, приватный режим, исходный файл, паспорт и запрет публикации. У Suno сильнее язык уступки прав, но уже лицензия сервису и оговорка про copyright. У MusicGPT слабее язык владения и неясна приватность API, зато есть явная выгрузка WAV из API и (на вебе) файл лицензии.

## 7. Выводы для юриста (не юридическое заключение)

1. Платный тариф MusicGPT, скорее всего, даёт договорное коммерческое право использовать генерацию – **высокая** уверенность по тексту ToS.
2. Это не доказанная уступка исключительных прав и не гарантия авторского права по ГК РФ – **средняя/низкая**.
3. Лицензия сервису на showcase/distribute/training может конфликтовать с обещанием клиенту «эксклюзивного закрытого каталога» – вопрос юристу.
4. Публичное исполнение в заведении прямо не покрыто текстом – вопрос юристу и, желательно, письменный ответ MusicGPT.
5. Расхождение «Ltd» в ToS и возможного «LLC» в PDF нужно снять, когда будет образец сертификата.
