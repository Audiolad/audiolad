Редакция 1 от 15.11.2026 (Europe/Moscow). Статус: проект для решения Сергея.

Задача Core `90338dcc`: техническо-правовая проверка и проект полуавтоматического конвейера первого этапа для новой эксклюзивной музыки АудиоЛад Бизнес. **Продукт не менялся. Генерации не запускались. Планы и API-кредиты не покупались. Письма и уведомления не отправлялись.**

Этот PR – отдельная документальная база, в параллельную кодовую работу режима «только Бизнес» не вмешивается.

## Короткий итог

Рекомендация: **гибрид**. Генерацию, идентификаторы и исходные WAV можно вести через официальный API `POST /v2/MusicAI`. Публичного API для Ownership License PDF и для переименования уже созданного `conversion_id` нет. Приватность API-генераций (не попадают ли они в Discover) в официальных API-документах не описана. Полностью автоматический путь сейчас заблокирован этими пробелами.

Расходов в этой задаче нет.
