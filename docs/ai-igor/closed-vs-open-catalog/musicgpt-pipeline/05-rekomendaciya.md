# Рекомендация и вопросы

## Рекомендация

**Гибридный путь**, не полная автоматизация и не блокер навсегда.

Почему не «полностью автоматический API-путь»: публичного метода Ownership License PDF нет; переименования готового `conversion_id` нет; приватность API-генераций официально не описана; связь веб-кабинета и API-аккаунта не подтверждена. Автомастеринг и публикация по постановке и не нужны.

Почему не блокер целиком: официальный API умеет то, что составляет ядро первого сегмента – запрос с промптом, два выхода, идентификаторы, оценка стоимости, webhook или опрос, скачивание оригинального WAV. Платные планы по документации включают commercial use, а ToS даёт платным пользователям full commercial rights (с оговорками из [01-prava-i-usloviya.md](01-prava-i-usloviya.md)).

Практическая схема:

1. Оркестратор на нашей стороне вызывает только официальный `POST /v2/MusicAI` и `GET /v1/byId`, скачивает WAV, ведёт журнал и хеши.
2. Сергей отбирает звук и назначает названия.
3. PDF лицензии – вручную, пока MusicGPT не укажет официальный API или явный способ для API-треков.
4. Паспорт – по шаблону пилота / регламенту PR #1261.
5. Мастеринг – вручную в BandLab. В каталог и залы – только после режима «только Бизнес» и допуска по регламенту.

Для качества закрытого каталога разумный тариф API – **API Pro** и модель **`v7` или `v7-pro`**: только на Pro эти модели доступны. Если важнее экономия абонентки, Plus + `v6` дешевле (19 $ /month против 69 $), но без v7.

## Трудозатраты (оценка, не факт)

| Работа | Оценка |
|---|---|
| Письма в поддержку MusicGPT и разбор ответа | 1–3 часа |
| Юрист: коммерческие права, лицензия сервису, залы, Ltd/LLC | отдельно, по договорённости Сергея |
| Скрипт оркестратора первого сегмента (без публикации, без продукта) | 1–2 рабочих дня |
| Прогон одного альбома после разрешения на расход: отбор звука Сергеем | примерно сессия слушания 10 файлов + время на перегенерации |
| Паспорта, хеши, раскладка архива | 2–4 часа на альбом в полуручном режиме; меньше, когда шаблон заполняется из `generation.json` |

Реализация скрипта, покупка плана и вызовы API в эту задачу **не входят**.
