Все суммы ниже – по официальной странице [Pricing Plans](https://docs.musicgpt.com/api-documentation/index/pricing) на 15.11.2026 (Europe/Moscow). Планы, кредиты и генерации в этой задаче **не покупались и не вызывались**. Курсы валют и комиссия карты не считались: тарифы сервиса в долларах США.

Changelog: структура цен AI Music Generator обновлена с 1 августа (год в changelog – 2026). Годовая оплата «фиксирует текущую цену», как написано на той же странице; это заявление документации, не наш аудит будущих изменений.

## 1. Абонентская плата API (официально)

Из кода официальной страницы документации (переключатель Monthly / Yearly, 15.11.2026):

| План | Помесячно | За год, в пересчёте на месяц | Что даёт по docs |
|---|---|---|---|
| Pay as you go | Абонентской платы нет; заранее вносятся кредиты | – | Ставки за запрос выше. `v7` / `v7-pro` / `v6-pro` для AI Music **недоступны**. |
| API Plus | **19 $ / month** | **14,99 $ /mo**, «Billed annually» | Ниже ставки, чем PAYG. Модели AI Music: `v6` и `v6-pro`. Параллельность генераций: 3. |
| API Pro | **69 $ / month** | **49,99 $ /mo**, «Billed annually» | Самые низкие ставки, выше лимиты, приоритетная обработка. Доступны `v7` и `v7-pro`. Параллельность: 10. FAQ: сначала базовая плата 69 $, кредиты пополняются отдельно и списываются по ставке плана. |
| Enterprise | «Contact Us» | – | Индивидуально, api@musicgpt.com. |

Документация прямо: планы (кроме PAYG) **не включают** пакет кредитов, а **снижают** цену каждого вызова. «All paid plans include commercial use». Отнесён ли PAYG к «paid plans» в смысле ToS – **не подтверждено**; для закрытого каталога закладываем Plus или Pro, не бесплатный тариф и не «серую» зону PAYG.

Активация API-аккаунта по docs требует платёжных данных; обещано до 10 бесплатных генераций песен. Это не проверялось и в смету пилота не включено как гарантированный ноль.

## 2. Ставка за одну песню AI Music (официально)

Один вызов Music AI даёт **2 версии**, плата – **за каждую песню**. Значит, один вызов стоит `2 × ставка модели`.

| Модель | API Pro | API Plus | Pay as you go |
|---|---|---|---|
| `v7-pro` | 0,06 $ / song | недоступна | недоступна |
| `v7` | 0,05 $ / song | недоступна | недоступна |
| `v6-pro` | 0,045 $ / song | 0,06 $ / song | недоступна |
| `v6` | 0,035 $ / song | 0,05 $ / song | 0,10 $ / song |

WAV в документации Music AI не тарифицируется отдельно: путь WAV приходит в webhook / `byId`. Отдельной платы за скачивание исходника в API-документации нет (в отличие от веб-тарифа Free, где скачивание стоит кредиты).

Перегенерация, File Convert, Mastering API в базовый расчёт одного альбома не входят, кроме явно помеченного запаса.

## 3. Один альбом: 5 вызовов = 10 песен

Плата за генерацию (без абонентки), если все 10 выходов приняты и перегенераций нет:

| Модель и план | 10 песен | 5 вызовов, пояснение |
|---|---|---|
| `v7-pro`, API Pro | **0,60 $** | 10 × 0,06 |
| `v7`, API Pro | **0,50 $** | 10 × 0,05 |
| `v6-pro`, API Pro | **0,45 $** | 10 × 0,045 |
| `v6`, API Pro | **0,35 $** | 10 × 0,035 |
| `v6-pro`, API Plus | **0,60 $** | 10 × 0,06 |
| `v6`, API Plus | **0,50 $** | 10 × 0,05 |
| `v6`, PAYG | **1,00 $** | 10 × 0,10; права PAYG – не подтверждено |

К этому нужно добавить абонентскую плату месяца (или доли года), в котором идёт сессия. Если в месяце делается только один альбом:

| Сценарий | Генерация | Абонентка (месяц) | Итого, нижняя оценка |
|---|---|---|---|
| Рекомендуемый для качества: API Pro + `v7-pro` | 0,60 $ | 69 $ | **69,60 $** |
| API Pro + `v7` | 0,50 $ | 69 $ | **69,50 $** |
| API Pro, год, пересчёт: + `v7-pro` | 0,60 $ | 49,99 $ | **50,59 $** (плюс факт годового платежа 12 × 49,99 $ = 599,88 $, если подписка на год) |
| API Plus + `v6` | 0,50 $ | 19 $ | **19,50 $** (модели v7 нет) |

Запас на отбраковку. Регламент запрещает считать любую пару автоматически удачной. Запас – **оценка, не факт**. Если закладывать, например, +20 % песен (ещё 1 вызов = 2 песни) на Pro/`v7-pro`: +0,12 $, всё ещё копейки против 69 $. Если отбраковка высокая и нужно заново сделать весь альбом – ещё раз 0,60 $ плюс время Сергея, не вторая абонентка в том же оплаченном месяце.

Веб-тарифы (не API), для справки, с публичной страницы `musicgpt.com/pricing` 15.11.2026: Free 0 $; Plus 9,99 $ /month; Pro 16,99 $ /month; Ultra 32,99 $ /month. Commercial use, Download license и Stealth – у Plus и выше, у Free нет. Это тарифы сайта, не API. Нужны ли они дополнительно, чтобы скачать PDF лицензии, – **не подтверждено**. Если понадобится отдельный веб-план, его надо добавить к смете отдельно, не смешивая со ставками API.

## 4. Условно 20 альбомов

20 × 5 вызовов = 100 вызовов = 200 песен, если нет перегенераций.

| Сценарий | Генерация 200 песен | Абонентка | Итого, нижняя оценка |
|---|---|---|---|
| 20 альбомов за один месяц, API Pro + `v7-pro` | 12,00 $ | 69 $ | **81,00 $** |
| То же + запас 20 % песен | 14,40 $ | 69 $ | **83,40 $** |
| 20 альбомов за один месяц, API Pro + `v6` | 7,00 $ | 69 $ | **76,00 $** |
| Те же 20 альбомов, но растянуты на 3 месяца Pro | 12,00 $ | 3 × 69 $ = 207 $ | **219,00 $** |
| Годовой API Pro (599,88 $) + 20 альбомов `v7-pro` | 12,00 $ | 599,88 $ / год | Имеет смысл только если альбомов за год будет заметно больше 20; иначе месяц дешевле |

Формула, если число альбомов, модель или запас изменятся:

`стоимость генераций = альбомы × 5 вызовов × 2 песни × ставка × (1 + доля перегенерации)`  
`итого = стоимость генераций + число месяцев подписки × цена плана`  
(для годового плана – разовая годовая плата вместо суммы месяцев).

Не включено и помечено «не подтверждено»: комиссия банка, отдельный веб-план ради PDF, платный File Convert, работа юриста, время мастеринга в BandLab, хранение архива.

## 5. Минимальный MVP после согласования расходов

Когда (и только когда) Сергей утвердит бюджет и ключ, самый малый проверяемый шаг:

1. Один тестовый вызов API Pro (или согласованный план): 2 WAV, без публикации, сразу в закрытый архив, хеши, запись в журнал.
2. Попытка вручную получить PDF лицензии на эти два выхода.
3. Если приватность и лицензия подтверждены на практике – один полный альбом по конвейеру (5 вызовов).

Стоимость шага 1: 2 × ставка (для `v7-pro` 0,12 $) + уже оплаченная абонентка месяца. Без утверждения бюджета этот шаг **не делается**.
