# Чек-лист допуска трека в Бизнес (одна страница)

Трек: ____________  Код AL-T: ____________  Проект: ____________  Дата: ________

Подробности по каждому пункту – `01-reglament.md`. Любой «нет» в блоке «Стоп» – трек не допускается.

## Генерация и происхождение
- [ ] Тариф с коммерческими правами оплачен на дату генерации: скриншот + чек (хэши в описи)
- [ ] Копия условий сервиса на дату генерации
- [ ] Генерация приватная, не публиковалась в сервисе
- [ ] ID / ссылка генерации, дата, модель – скриншот карточки
- [ ] Промпты полностью (все итерации), без имён артистов и названий чужих песен
- [ ] Исходный файл из сервиса без перекодирования
- [ ] Проект DAW / список правок (если были)
- [ ] Заявление: **А** «человеческого автора нет» или **Б** «есть вклад человека: …»

## Файлы и хэши
- [ ] Мастер в рабочем хранилище АудиоЛад
- [ ] Мастер и исходник в неизменяемом архиве (второе место)
- [ ] SHA-256: исходник, мастер, каждая кодировка, каждое доказательство – в `SHA256SUMS`
- [ ] Хэш описи внесён в общий реестр с датой
- [ ] После загрузки: хэш в хранилище = хэш мастера = `source_sha256` техпаспорта

## Проверка
- [ ] Shazam: «не найдено» – скриншот с датой
- [ ] ACRCloud: нет совпадений – ответ с датой (после проверки условий сервиса)
- [ ] AcoustID: нет совпадений
- [ ] Собственный отпечаток (Chromaprint / audfprint): файл, версия, параметры, хэш
- [ ] Нет заметного сходства с известными произведениями

## Паспорт
- [ ] Обязательные разделы 1, 2, 3, 4, 5, 8, 9, 11 заполнены
- [ ] Изготовитель – ИП Петров С. С.; договоров с РАО / ВОИС / дистрибьюторами по треку нет

## Закрытый каталог
- [ ] Альбом в режиме «только Бизнес» (после будущего PR; до него – не публиковать)
- [ ] Страница альбома и трека без входа – 404 / нет доступа (проверено, скриншот)
- [ ] Нет в sitemap, каталоге, поиске, Студии, плейлистах, встраиваемом плеере
- [ ] Не отправлялся дистрибьюторам и в соцсети
- [ ] Допущен в нужные направления и время суток

## Стоп (любое «да» – не допускать)
- [ ] Тариф без коммерческих прав / не оплачен на дату
- [ ] Генерация или трек где-либо опубликованы
- [ ] Нет исходника или промпта
- [ ] Заявление о вкладе не выбрано или противоречит файлам
- [ ] Совпадение с чужой записью или заметное сходство
- [ ] Страница открывается без входа
