Задача Company Core: `e3f7dd1e-01ab-4545-9eb9-e493c3059d56`.

Дата исследования: 23 октября 2026 г. Документ только для решения Сергея. Регистраций, оплат, ключей и интеграций по этой задаче нет. Площадки ниже – дополнительный независимый канал. Они не заменяют текущий контур статей, Cursor и уже подключённый Product SEO Autofill.

Если цифры на маркетинговой карточке расходятся с тарифным приложением, в расчёт берётся тарифное приложение. Всё, что не удалось подтвердить, собрано в разделе 10 и нигде не подставлено как факт.

## 1. Решение, которое предлагается принять

| Роль | Площадка | Зачем |
|------|----------|--------|
| Основной кандидат для фабрики статей | Cloud.ru Evolution Foundation Models внутри Evolution AI Factory | Есть публичный OpenAI-совместимый API, оплата в рублях, внутренние модели без выноса запроса наружу по документации Cloud.ru, цена за токен опубликована |
| Резерв | VK Cloud / VK AI Space | Российский контур и оплата из РФ подтверждены. Готового дешёвого текстового API с прайсом нет. Имеет смысл только после коммерческого предложения, не как старт пилота |
| Кандидат для разработки, не для статей | Yandex SourceCraft Code Assistant | Плагин IDE и агент по репозиторию. Это запасной канал программирования рядом с Cursor. Для массовых SEO-статей он не подходит |
| Не делать | Автопубликация, выдача секретов, подключение продакшен-репозитория к агенту | Публикация остаётся на текущем `release-article.sh` и ручном допуске |

- VK: **0 ₽**, пока нет оферты с ценой.
- Итого потолок при одобрении обоих контуров: **4 190 ₽** за первый месяц. Ожидаемые обязательные траты без SourceCraft – предоплата Cloud.ru в пределах потолка, фактически спишется малая часть.

Это цена моделей. Время редактора в рублях здесь не оценено: ставки в репозитории нет.

## 2. Что в репозитории уже есть и чего нет

Фабрика статей в коде не запущена. Статья – это TypeScript-модуль, который человек собирает, коммитит и выпускает отдельным скриптом.

Проверенные факты рабочей копии `main` на дату исследования:

| Факт | Где смотрели | Что там |
|------|----------------|---------|
| Два типа статей в `ArticleDefinition` | `src/lib/seo/articles/types.ts` | `practice` с обязательной практикой и `creator` с `creator_paths`. Тип `listen` живёт отдельно в `src/lib/seo/listens` и в этот тип не входит |
| Объём корпуса | `src/lib/seo/articles/content/*.ts` | 103 файла: 74 `practice`, 29 `creator_paths` |
| Длина текста | те же файлы, подсчёт строковых литералов 23.10.2026 | Медиана около 1 416 слов и 11 590 знаков. Нижняя четверть 1 336 слов, верхняя 1 892. Самый короткий файл около 814 слов, самый длинный около 5 079 |
| Скорость чтения в продукте | `src/lib/seo/articles/reading-time.ts` | 180 слов в минуту. Медианная статья – примерно 8 минут чтения |
| Реестр | `docs/seo/operational/SEO_OPERATIONAL_MASTER.json` | 102 записи со статусом `PUBLISHED`. `nextQueue` пустой. Поле `generatedAt` в файле: `2026-08-12T10:21:24Z`. Оно может быть старше последних статей |
| Старый отчёт сверки | `docs/seo/operational/RECONCILIATION_REPORT.md` | Описывает более ранний срез: 63 опубликованных и пустую очередь. На текущий JSON опираться точнее |
| Правило очереди | `docs/seo/operational/README.md` | Новая статья попадает в Next Queue только из зафиксированного плана: стабильный ID, основной запрос, частотность, хаб, привязка практики |
| План 50 | `docs/ai-visibility/README.md` | Редакционный контур назван как `tmp/seo-inventory/`, Editorial Master и Plan 50. Каталог `tmp/` в gitignore. В этой рабочей копии плана нет |
| Выпуск | `deploy/scripts/release-article.sh`, `scripts/release-article-lib.mjs` | Публичный URL проверяется смоуком. Автопубликации из модели нет |
| Короткий SEO карточки товара | `docs/product-seo-autofill.md` | Отдельный контур: OpenAI или Yandex AI Studio, черновик полей карточки, не статья. Бюджет вызовов до 3, у OpenAI в документе `max_output_tokens=3000`. Это не фабрика статей |
| Лимиты Cursor в репозитории | поиск по docs | Абсолютной квоты токенов или числа статей нет. Есть только предупреждение не гонять массовые прогоны без нужды |

Типы статей не взаимозаменяемы. `practice` требует живую практику каталога. `creator` ведёт в Студию и «25 готовых решений» и не использует аудиоблок практики. `listen` требует явный `playlistSlug` и не собирается из `ArticleDefinition`. Модель не имеет права угадывать тип.

Текущая себестоимость статьи – это время редактора и разработчика плюс расход агента Cursor на сборку файла. Официальный прайс Cursor на 23.10.2026 (`https://cursor.com/docs/models-and-pricing`, `https://cursor.com/pricing`) описывает планы X Subscription: Free, Plus 8 USD в месяц, Premium 30 USD, Super 100 USD, Ultra 200 USD. Платные планы дают недельный пул моделей Cursor. Размер пула в токенах или в запросах на страницах не опубликован: указаны множители Base, 4x, 15x, 50x. Какой план стоит у АудиоЛада, в репозитории не записан. Поэтому стоимость 1, 100 и 1 000 статей «через Cursor» в рублях посчитать нельзя. Качественный вывод другой: тысяча статей через IDE-агента упирается в недельный пул и в ручную сборку TypeScript. Для регулярного текста нужен API с ценой за токен и отдельным редакционным допуском.

## 3. Два контура, которые нельзя смешивать

| | Генерация SEO-текста по API | Агентная разработка в репозитории |
|--|------------------------------|-------------------------------------|
| Вход | Карточка материала: тип, запрос, хаб, разрешённые URL, факты | Репозиторий, терминал, дифф, тесты |
| Выход | Черновик полей статьи | Правки файлов |
| Кто решает публиковать | Человек, затем существующий скрипт выпуска | Человек, ревью, CI |
| Что нельзя отдавать модели | Секреты, `.env`, приватные ключи, непроверенные частотности как факты | Продакшен-доступ, служебные хосты, боевые секреты |
| Подходящая площадка из трёх | Cloud.ru Foundation Models | SourceCraft Code Assistant, и только как запасной канал |
| Неподходящая подмена | SourceCraft и VK AI Space без текстового прайса | Foundation Models сами по себе репозиторий не ведут. Агенты Cloud.ru – отдельный сервис и не замена Cursor |

## 5. Cloud.ru Evolution AI Factory

Доступ проверен 23.10.2026.

### 5.1. Что это

Страница продукта: `https://cloud.ru/products/evolution-ai-factory`.

AI Factory – набор сервисов, а не одна модель:

| Сервис | Роль для АудиоЛада |
|--------|--------------------|
| Evolution Foundation Models | Готовые модели по API. Это контур SEO-текста |
| Evolution ML Inference | Свой или выделенный инференс на GPU. Дороже, нужен только при упирании в лимит общей очереди |
| Evolution AI Agents | Мультиагентные системы. Оплата vCPU/RAM плюс токены моделей. Это не замена Cursor и не нужна для черновика статьи |
| Evolution Managed RAG | Поиск по своим документам. Для статей не обязателен: факты должны приходить в карточке, а не из свободного поиска |
| ML Finetuning, Notebooks | Дообучение и эксперименты. В пилот не входят |

Страница Foundation Models: `https://cloud.ru/products/evolution-foundation-models`. API описан как совместимый с OpenAI. Эндпоинт в справочнике: `https://foundation-models.api.cloud.ru/v1/`. Документация API: `https://cloud.ru/docs/foundation-models/ug/topics/api-ref`.

Начало работы по их инструкции: личный кабинет, выбор модели, ключ, запрос. Этот шаг в данной задаче не выполняется.

### 5.2. Внутренние и внешние модели

Каталог: `https://cloud.ru/docs/foundation-models/ug/topics/overview__available__models`.

Формулировка документации:

- внутренняя модель работает внутри инфраструктуры Cloud.ru, данные пользователя не логируются и не хранятся в Cloud.ru;
- внешняя модель ходит во внешний API, данные уходят из инфраструктуры Cloud.ru.

Юридическое описание услуги, приложение №1.EVO.11.2, версия файла 260430: `https://cdn.cloud.ru/docs/legal/contracts/terms-of-service/evolution/current-version/description-foundation-models.pdf`.

Для моделей, развёрнутых у Cloud.ru: модель не обращается наружу, дообучение на стороне исполнителя не производится, третьим лицам доступ в контур заказчика не даётся. Для внешних моделей запрос уходит провайдеру, и Cloud.ru снимает с себя ответственность за обработку. Заказчик обязан сопроводить результат информацией о создании с помощью услуги. Точность результата исполнитель не гарантирует.

Маркетинговая фраза «модели развернуты на российских серверах» на странице Foundation Models шире, чем каталог. Для статей допустимы только строки каталога со размещением «Внутренняя». Внешние модели (Claude, GPT, Gemini, часть DeepSeek и Qwen) в фабрику не брать: запрос уйдёт наружу, и в черновике могут оказаться ещё не опубликованные формулировки плана.

Город конкретного кластера инференса отдельной строкой не указан. Страница AI Factory говорит о 9 дата-центрах Tier III. Точный адрес площадки: **неподтверждено**.

## 8. Экономика SEO-статьи

### 8.1. Допущения, все сразу

Цифры этого раздела – сценарий планирования, не замер живого API. Токенизатор моделей не вызывался.

1. Целевая статья по длине совпадает с медианой корпуса: около 1 400 слов русского текста. В токенах планирования это **4 000 выходных токенов** на полный текст. Опора: 1 416 слов × грубо 2,5 токена на слово ≈ 3 540, округление вверх до 4 000 с запасом на служебные поля. Это допущение. Реальный токенизатор может дать и 3 000, и 6 000.
2. Карточка и системная инструкция: **2 000 входных токенов**. В них тип статьи, запрос, хаб, разрешённые ссылки, факты практики, запрет выдумывать. Редакционные секреты и ключи туда не входят.
3. Три полных прохода на одну статью:
   - проход 1, черновик: вход 2 000, выход 4 000;
   - проход 2, SEO-проверка тем же API: вход 6 000 (инструкция и черновик), выход 4 000;
   - проход 3, правка по замечаниям редактора: вход 6 500, выход 4 000.
4. Итого базовый сценарий: **14 500 входных и 12 000 выходных токенов** на статью.
5. Человеческая редактура идёт после третьего прохода и в рублях API не сидит. Без неё статья не публикуется.
6. Частотность Wordstat модель не выдумывает и не «проверяет». Если в карточке частотности нет, в тексте её нет.
7. Цены – колонка «с НДС» приложения №7.EVO.11.2 от 15.10.2026. Округление в договоре Cloud.ru идёт вверх до копейки на каждой группе токенов. В таблице ниже показана прямая пропорция, без этого округления. На одной статье расхождение меньше копейки. На 1 000 статей оно не меняет вывод.

## 9. Пилот на 10 статьях

### 9.2. Единые критерии качества

Оценка бинарная там, где ошибка блокирует приём, и по шкале 0, 1, 2 там, где нужна степень. Принимает редактор. Модель сама себе оценку не ставит.

| Критерий | Блокер | Как смотреть |
|----------|--------|----------------|
| Точность | Да | Нет выдуманных исследований, процентов, цитат, цен, имён врачей и «доказано, что». Факт либо есть во входной карточке и в публичной практике, либо его нет в тексте |
| Польза | Нет, шкала | Текст отвечает на запрос и даёт различимые шаги. Пустая мотивация – 0 |
| Структура | Да для приёма в корпус | Для `practice`: лид, короткий ответ, разделы H2, FAQ, закрытие, слот практики. Для `creator`: без слота практики и без аудиоблока. Для будущего `listen`: отдельный модуль, в этом пилоте не используется |
| Таблицы | Да, если таблица есть | Таблица только когда во входе есть реальные строки для сравнения. Пустые или выдуманные ячейки – блокер. Если таблице неоткуда взяться, её не должно быть |
| Ключевые слова | Нет, шкала | Основной запрос есть в заголовке или лиде и не повторён механически в каждом абзаце. Если запроса во входе нет, модель его не выдумывает |
| Внутренние ссылки | Да | Разрешены только URL из карточки: хаб, практика, «смотрите также». Новый slug – блокер |

Ожидаемая цена этого прогона по разделу 8: около 10 × 0,96 ₽ плюс 10 × 7,14 ₽ = **81 ₽**. Запас на лишние проходы до **162 ₽**. Потолок счёта всё равно 3 000 ₽.
