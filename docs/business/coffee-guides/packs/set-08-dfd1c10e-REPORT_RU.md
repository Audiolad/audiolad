В intent каждой темы явно закреплено partOne=2, partTwo=3; sectionsHint содержит ровно две записи до таблицы и три после. Для каждой темы обязательна таблица с короткими качественными значениями. Все links содержат не менее трёх разных зарегистрированных адресов; readMore состоит из объектов href/label и входит в links. В тексте будущей статьи нужно не менее трёх разных разрешённых ссылок. Схема строк ответа и штатный parseInline сохранены: сборщик превращает встроенные ссылки в объекты итогового модуля. Пробелы перед адресом и обратные слэши запрещены.

Для каждого ответа в intent переданы конкретные ориентиры seoTitle и description с проверенной длиной. Произвольные поля верхнего уровня статьи загрузчик не переносит, поэтому ориентиры помещены именно в поддерживаемый intent, без изменения шаблона. Длины description: 149 / 142 / 146 / 154 / 144 символов соответственно №36–40. Основной запрос присутствует дословно, включая №40. Для №40 title/H1 дан в естественном порядке «Поставщики десертов для кофейни», seoTitle начинается с дословного запроса, первый абзац должен содержать его дословно. H2 сохраняет все слова запроса. Это согласовано с реальными проверками rules.mjs. Итоговые поля будущего ответа Райтера всё равно требуют повторной проверки.
