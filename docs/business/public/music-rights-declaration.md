## 1. Заверения об обстоятельствах (ст. 431.2 ГК РФ) — по каждому треку приложения 1
1.1. По каждому треку и каждому охраняемому элементу (с учётом п. 1.3) правообладатель является: (а) автором (единственным или с соавторами по приложению 1) музыкального произведения; (б) исполнителем всех партий либо обладает правами исполнителей по договорам (приложение 2); (в) изготовителем фонограммы.
1.2. Сэмплы, лупы, библиотеки звуков и пресеты третьих лиц указываются по каждому треку в приложениях 1–2 (при отсутствии — «нет»).
1.3. Использование систем искусственного интеллекта указывается по каждому треку в приложении 1: «не использовался», «как инструмент» (какой и для чего) или «генерация» (сервис, тариф, дата, учётная запись), с описанием творческого вклада человека. Правообладатель подтверждает, что условия сервиса на дату генерации разрешают коммерческое использование результата, включая публичное исполнение. Условия сервиса искусственного интеллекта не создают авторства: по каждому такому треку описываются творческий вклад человека и охраняемые элементы (ст. 1228, 1257 ГК РФ); на полностью сгенерированные фрагменты исключительные права не заявляются.
1.4. Исключительные лицензии, отчуждение, залог, передача в управление организациям по управлению правами (РАО, ВОИС, иным), эксклюзивность у дистрибьюторов указываются в приложении 2 (при отсутствии — «нет»).
1.5. Притязаний и споров третьих лиц нет.
1.6. Правообладатель обязуется немедленно сообщить об изменении любого заверения; такое изменение — основание блокировки трека до выяснения.

## 2. Способы, по которым выдаются лицензии точкам (каждый отдельно, прекращаются отдельно)
Схема доставки: файл хранится на серверах оператора и сети доставки → кодируется → передаётся по сети на авторизованный плеер точки → при необходимости записывается в защищённый кэш → публично исполняется в помещении. Каждое действие разрешается отдельно по произведению, исполнению и фонограмме (ст. 1270, 1317, 1324 ГК РФ).
2.0. **Технические копии:** запись треков на серверах оператора и подрядчиков хранения, перекодирование — только для целей пп. 2.1–2.2.
2.1. **Фоновое воспроизведение для бизнеса** — передача трека на авторизованный плеер и его публичное исполнение как фоновой музыки в помещении организации-пользователя «АудиоЛад Бизнес».
2.2. **Кэш для работы без связи** — запись в защищённое хранилище авторизованного плеера только для п. 2.1, без возможности извлечения пользователем, не более 7 суток с последней проверки прав со связью; удаление или блокировка при истечении срока, отзыве, прекращении доступа.
2.3. **Техническая обработка** без переработки произведения: кодирование, выравнивание громкости, плавные переходы между треками, не изменяющие произведение.
2.4. Лицензии точкам выдаются правообладателем напрямую в пределах пп. 2.1–2.3, на срок доступа точки, но не дольше срока и объёма прав по этому заявлению.
2.5. Не разрешаются: скачивание и продажа файлов, синхронизация с видео и рекламой, использование в рекламных роликах, ремиксы, выдача отдельных дорожек, распространение вне сервиса.

## 3. Территория и сроки
3.1. Территория — Российская Федерация: место нахождения точки; для технических копий (п. 2.0) — серверы оператора и его подрядчиков хранения.
3.2. Срок — на срок действия исключительного права на соответствующий объект (ст. 1281, 1318, 1327 ГК РФ), прямо указанный во избежание п. 4 ст. 1235 ГК РФ (5 лет по умолчанию).
3.3. Трек выходит в коммерческий эфир только после того, как по нему получены и проверены документы о правах. Подтверждение одного трека никогда не подтверждает каталог; статус подтверждения автоматически не присваивается.

## 4. Учёт, вознаграждение, отчёты
4.1. Оператор фиксирует по каждой точке фактические воспроизведения и хранит сведения о них **5 лет**.
4.2. Вознаграждение — по единой модели вознаграждения сервиса.
4.3. Заявление **не затрагивает** обязательное вознаграждение исполнителям и изготовителям за публичное исполнение фонограмм, опубликованных в коммерческих целях (ст. 1326 ГК РФ), и не прекращает расширенное коллективное управление РАО (п. 3 ст. 1244 ГК РФ). Применимость ст. 1326 ГК РФ устанавливается **по каждой фонограмме** (факт и способ публикации); исключение из управления РАО возможно только по процедуре п. 4 ст. 1244 ГК РФ и относится к правообладателю, не заключавшему договор с РАО.

## 5. Снятие трека (договорное; не путать с правом автора на отзыв по ст. 1269 ГК РФ)
5.1. Плановое снятие — полностью, по треку или по способу, с уведомлением за **30 дней**; момент прекращения — дата окончания срока уведомления.
5.2. Экстренное снятие (претензия третьего лица, изменение заверений) — немедленное исключение из программы. Правообладатель **разрешает** доигрывание ранее сохранённых для работы без связи треков (не более 7 суток) при экстренном договорном снятии, кроме случаев запрета закона или суда либо установленного отсутствия прав.
5.3. С момента уведомления о снятии каждый сохранённый для работы без связи трек доступен не дольше ранней из дат: последняя проверка со связью плюс 7 суток или момент прекращения права; в этот момент воспроизведение прекращается на устройстве даже без связи. Если плеер не может гарантировать такую остановку, кэш для трека отключается.
5.4. Снятие не аннулирует историю использования и начислений.
