# Условия лицензирования музыки для бизнеса

Раздел оферты сервиса «АудиоЛад Бизнес». Редакция от 16.10.2026.

Лицензиар — оператор сервиса: ИП Петров Сергей Сергеевич, ИНН 507305817690, ОГРНИП 316505300063237.

1. **Что получает клиент.** Простую неисключительную лицензию на публичное исполнение треков каталога «АудиоЛад Бизнес» как фоновой музыки **в конкретной точке** (адрес, зона), указанной в личном кабинете, через плеер АудиоЛад, в период доступа. Правообладатель каждого трека указывается по данным реестра прав сервиса. По трекам, права на которые принадлежат лицензиару, предоставляется **прямая лицензия**; по трекам других правообладателей — **сублицензия** на основании их письменного согласия (п. 1 ст. 1238 ГК РФ). Объём и срок лицензии клиента не превышают объёма и срока прав лицензиара по каждому треку.
2. **Территория** — точка на территории Российской Федерации. Перенос на другой адрес оформляется как новая точка.
3. **Способ** — только воспроизведение через плеер сервиса. Плеер **автоматически** создаёт защищённый кэш для работы без связи (только для треков, где это разрешено, не дольше 7 суток без связи и не позже момента прекращения прав) — это разрешённое исключение из запрета записи. Запрещено: иная запись, скачивание, извлечение файлов, перезапись, использование в рекламе, видео и социальных сетях, трансляция за пределы точки, передача доступа третьим лицам, переработка.
4. **Срок и цена** — пока действует доступ к точке. Пробный и пилотный доступ — **безвозмездная** лицензия на срок пробного или пилотного периода; при платном доступе лицензионное вознаграждение входит в тариф (п. 5 ст. 1235 ГК РФ). По окончании доступа воспроизведение прекращается; личный кабинет и документы остаются доступны.
5. **Только подтверждённые треки** — сервис выдаёт в эфир только треки, права на которые подтверждены для страны и типа точки. Подтверждение делается по каждому треку отдельно: подтверждение одного трека не распространяется на каталог.
6. **Учёт** — сервис ведёт журнал фактических воспроизведений по точке: трек, время начала и окончания (по всемирному времени и по часовому поясу точки), длительность (включая неполные), режим со связью или без связи, состояние прав на момент воспроизведения. Воспроизведения без связи передаются после её восстановления, повторы устраняются; исправление отчёта — по обращению клиента; хранение — 5 лет. Клиент может выгрузить отчёт за период для проверок и организаций по управлению правами.
7. **Снятие трека** — плановое: с уведомлением правообладателя за 30 дней, трек заменяется в программе автоматически; экстренное (претензия третьего лица): немедленно из программы; ранее сохранённые для работы без связи треки — в пределах срока, указанного в п. 3. Если из-за снятий программа точки становится непригодной, клиент вправе отказаться с возвратом за неиспользованный период или получить продление.
8. **Обязанности клиента:** использовать музыку только в указанной точке; не обходить плеер; обеспечивать связь плеера не реже одного раза в 7 суток; соблюдать нормы громкости, санитарные нормы и правила помещения; предъявлять документ точки при проверке; сообщать о закрытии или смене адреса; **самостоятельно исполнять обязанности перед организациями по управлению правами** в части, не покрытой лицензией (п. 9).
9. **РАО и ВОИС.**
   - Лицензия сервиса подтверждает разрешение правообладателя в её пределах. **Сама по себе** она не прекращает договор точки с РАО и не исключает расширенное коллективное управление (п. 3 ст. 1244 ГК РФ); исключение каталога из управления РАО возможно только по процедуре п. 4 ст. 1244 ГК РФ, и до её завершения сервис не обещает такого исключения.
   - За публичное исполнение фонограмм, опубликованных в коммерческих целях, закон предусматривает **вознаграждение** исполнителям и изготовителям фонограмм (ст. 1326 ГК РФ), которое уплачивает пользователь через аккредитованную организацию (ВОИС) с предоставлением отчётности; лицензия сервиса это вознаграждение не отменяет. Если по конкретной точке сервис берёт уплату такого вознаграждения на себя, это указывается отдельно в документе точки с основанием и подтверждением.
   - Сервис не обещает клиенту отсутствия платежей РАО и ВОИС и не засчитывает автоматически уже уплаченное.
10. **Гарантии сервиса** — наличие у сервиса прав по п. 1 на треки с подтверждёнными правами; при претензии третьих лиц по такому треку клиент уведомляет сервис, сервис участвует в защите и возмещает документально подтверждённые расходы клиента в пределах и в порядке, установленных «Порядком защиты клиента при претензиях».
