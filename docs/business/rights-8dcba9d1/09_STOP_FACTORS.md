# 09. Юридические стоп-факторы (до подписания и коммерческого использования)

| # | Стоп-фактор | Блокирует | Снимается чем |
|---|---|---|---|
| S1 | Нет заключения юриста по РАО/ВОИС (08 А–Б) | коммерческий запуск, текст 05 п. 9 и 06 | письменное заключение |
| S2 | Декларация 03 не подписана; 12 треков Аурафона в БД `verified` без документов | публичное использование **всех** треков, включая 12 и бесплатный пилот | 07 + заключение юриста + подпись; решение Сергея по 24 записям |
| S3 | Нет сведений об ИИ-генерации по каталогам | весь Jazz Relax; 38 треков Аурафона; подтверждение 12 | ответы 07 §1 + ToS на дату |
| S4 | Нет документов о создании (07 §2) | включение трека в B2B-пул (K5) | пакет доказательств по треку |
| S5 | Неизвестны дистрибьюторская эксклюзивность, членство в ОКУ, факты коммерческой публикации; процедура п. 4 ст. 1244 не проводилась | модель «прямые лицензии» | договоры/справки + решение по уведомлению РАО (после S1) |
| S6 | Есть соавторы/исполнители без договоров | соответствующие треки | договоры/согласия |
| S7 | Профиль RU `client_requirement = none` — непроверенное допущение, вероятно неверное (ст. 1326, п. 3 ст. 1244) | публичное использование и формулировки клиентам | заключение S1, затем отдельная задача на правку профиля |
| S8 | Авторские условия 1.1 не покрывают B2B | подключение будущих авторов | 04 + новая версия условий |
| S9 | Нет документа точки (K12) | пилотная точка K16 | 06 реализован после S1 |

Стоп-факторы применяются **к каждому треку и к пилоту**, без исключения для первых 12. Пока S1–S5 не сняты: **никакого** автоматического включения полного каталога, никаких обещаний клиентам «без РАО/ВОИС», никаких новых grants без отдельного решения Сергея.
