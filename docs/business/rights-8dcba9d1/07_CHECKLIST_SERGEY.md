# 07. Чек-лист: что нужно от Сергея (по каждому каталогу; отметить «есть/нет/не применимо»)

## 1. Общие сведения (один раз)
- [ ] Кто правообладатель Аурафон и Jazz Relax: Сергей лично (физлицо) / ИП / иное лицо; одно ли это лицо для обоих каталогов.
- [ ] Паспортные данные, адрес, ИНН, ОГРНИП — для декларации (передать не в чат, а в защищённый канал).
- [ ] Участвовал ли кто-то ещё (Зоя Петрова, сессионные музыканты, звукорежиссёр, аранжировщик, композитор по заказу)? Для каждого — ФИО и роль.
- [ ] Использовались ли сервисы ИИ (Suno, Udio, Mubert, AIVA, Soundraw, Stable Audio и др.) для: генерации трека целиком / мелодии / партий / вокализа / мастеринга? Какие каталоги и какие треки.

- [ ] Дистрибьюторы (ONErpm, Believe, Zvonko, DistroKid, …): договоры, исключительность, Content ID/YouTube, регистрация ISRC/UPC.
- [ ] Членство/регистрация в РАО, ВОИС, РСП или зарубежных ОКУ (лично или через дистрибьютора/издателя). Если «нет» — так и указать.
- [ ] Были ли договоры с издателями/библиотеками стоковой музыки об исключительных правах.
- [ ] Есть ли претензии, жалобы, Content-ID-споры по этим трекам.

## 2. По каждому треку (минимальный пакет доказательств)
- [ ] Исходный проект (DAW: Ableton/FL/Logic/…) или стемы с метаданными файлов и датами.
- [ ] Дата создания/записи и первой публикации (ссылки на релизы, если были на стримингах).
- [ ] Для ИИ-треков: история генерации (ID генерации, промпт, дата), описание ручной доработки.
- [ ] Для живых партий: договор/согласие исполнителя на коммерческое использование и публичное исполнение.
- [ ] Для соавторства: соглашение соавторов о распоряжении правами (ст. 1229 п. 3, ст. 1258).
- [ ] Подтверждение «без слов» (нет текста → нет автора текста).
