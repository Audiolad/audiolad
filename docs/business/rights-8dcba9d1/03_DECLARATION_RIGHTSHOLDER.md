## 2. Способы, по которым выдаются лицензии точкам (каждый отдельно, прекращаются отдельно)
Схема доставки: файл хранится на серверах/CDN оператора → кодируется → передаётся по сети на авторизованный плеер точки → (опц.) записывается в защищённый кэш → публично исполняется в помещении. Каждое действие разрешается отдельно по произведению, исполнению и фонограмме (ст. 1270, 1317, 1324); квалификацию передачи (сообщение по кабелю / доведение до всеобщего сведения / техническая передача) определяет юрист по реальному режиму доступа (08, вопрос 7).
2.0. **Технические копии:** воспроизведение (запись) Треков на серверах и CDN оператора и подрядчиков хранения, транскодирование — только для целей (А)–(Б).
2.1. (А) **Фоновое воспроизведение для бизнеса** — передача Трека на авторизованный плеер и его публичное исполнение как фоновой музыки в помещении организации-пользователя AudioLad Business.
2.2. (Б) **Офлайн-кэш** — запись в защищённое хранилище авторизованного плеера только для (А), без возможности извлечения пользователем, не более 7 суток с последней онлайн-проверки прав; удаление/блокировка при истечении, отзыве, прекращении доступа.
2.3. (В) **Техническая обработка** без переработки произведения: кодирование, нормализация громкости, плавные переходы между треками длительностью до [ ] с. [Юрист: не является ли кроссфейд переработкой — вопрос 9.]
2.4. Лицензии точкам выдаются правообладателем напрямую (оферта 05) в пределах (А)–(В), на срок доступа точки, но не дольше срока и объёма прав по этой декларации.
2.5. Не разрешаются: скачивание/продажа файлов, синхронизация с видео/рекламой, использование в рекламных роликах, ремиксы, стемы, распространение вне сервиса.

## 4. Учёт, вознаграждение, отчёты
4.1. Оператор фиксирует по каждой точке фактические воспроизведения (состав журнала — 05 п. 6) и хранит их **5 лет** (единый срок в 03–05 [юрист]).
4.2. Вознаграждение — по единой модели (черновик ROYALTY_MODEL_RU из задачи 0e05333f, в репозиторий не входит; для авторов формула — 04 п. 9), пока одно лицо — управленческий учёт.
4.3. Декларация **не затрагивает** обязательное вознаграждение исполнителям и изготовителям за публичное исполнение фонограмм, опубликованных в коммерческих целях (ст. 1326 ГК РФ), и не прекращает расширенное коллективное управление РАО (п. 3 ст. 1244). Применимость ст. 1326 устанавливается **по каждому мастеру** (факт и способ публикации); исключение из управления РАО возможно только по процедуре п. 4 ст. 1244 и относится к правообладателю, не заключавшему договор с РАО; при действующем договоре управления — отдельное урегулирование его прекращения/объёма (08, вопросы 2–3).

## 5. Снятие Трека (договорное; не путать с правом автора на отзыв по ст. 1269)
5.1. Плановое снятие — полностью, по Треку или по способу, с уведомлением за **30 дней**; T = дата окончания уведомления.
5.2. Экстренное снятие (претензия третьего лица, изменение заверений) — немедленное исключение из manifest. Правообладатель **разрешает** доигрывание ранее выданных офлайн-допусков (≤7 суток) при экстренном договорном снятии, кроме случаев запрета закона/суда или установленного отсутствия прав.
5.2а. **Правило офлайн-допуска (единое для 03–06):** T — момент прекращения права на Трек (окончание срока уведомления о плановом снятии, конец исходных прав или конец доступа точки). С момента получения уведомления/события каждый офлайн-допуск ограничивается датой `min(последняя онлайн-проверка + 7 суток, T)`; в момент T воспроизведение и доступ к кэшу прекращаются на устройстве даже без связи. При экстренном снятии (претензия, изменение заверений) Трек немедленно исключается из manifest; ранее выданные допуски сохраняют силу до своего окончания, только если это прямо разрешено исходной лицензией правообладателя и нет запрета закона/суда — иначе офлайн для таких Треков не включается. Если плеер не может гарантировать остановку в T без связи, офлайн-кэш для Трека отключается.
5.3. Снятие не аннулирует историю использования и начислений; последствия для лицензий точек (замена/перерасчёт) — по 05 п. 7 [юрист].
