## Главные выводы
1. Заявление Сергея «я полный правообладатель обоих каталогов» — **исходная гипотеза**, а не доказательство. Название артиста/псевдонима не подтверждает владение (п. 1.1 декларации v2).
2. В prod уже есть 24 записи `verified` (12 треков Аурафона × recording/composition, `business_background_playback`, RU, источник `other`, 13.10) — по одобрению Сергея 13.10 09:41 и неподписанной декларации v2. **Статус `verified` в БД не означает юридического подтверждения**: в реестре эти 12 треков — `UNCONFIRMED (расхождение с БД)`. Публичное использование любого трека, включая эти 12 и бесплатный пилот, — только после проверки цепочки прав и вопросов ОКУ (09). Решение по этим 24 записям (оставить для внутреннего теста / перевести в draft) — за Сергеем; этот пакет БД не меняет.
3. Jazz Relax: grants = 0, правообладатель в реестре не заведён, сведения о способе создания (в т.ч. AI) отсутствуют → весь каталог **WITHHELD** до документов.
4. Авторские условия AudioLad 1.1 регулируют B2C-доступ слушателей и лицензию Студии; **права на публичное исполнение в коммерческих точках они не предоставляют** → для будущих авторов нужен отдельный документ 04.
5. Договором с правообладателем **нельзя исключить** обязательное вознаграждение исполнителям и изготовителям фонограмм, опубликованных в коммерческих целях (ст. 1326 ГК РФ, ВОИС); отсутствие договора автора с РАО **не исключает** расширенное коллективное управление (п. 3 ст. 1244). Это вопросы к юристу, а не к шаблону.

Ревизия r2 (14.10): учтено независимое ревью (9 блокирующих замечаний: статус 12 треков, собственник vs лицензиат, РАО/ВОИС, способы и технические копии, отзыв vs кэш, существенные условия, цепочка прав/ИИ, сроки и заказ).
