# 14. Поштучный чек-лист ИИ-происхождения трека (Suno)

> **Черновик, требует проверки юриста.** Версия 0.1-draft от 16.10.2026 (задача 8dcba9d1, P0-3). Расширяет 07 (v2). Только документ и UI-тексты: хранение записей в БД — P1-5 / P1-4, **требует миграции** (не делается). Пока трек не прошёл чек-лист — статус **WITHHELD** (01).

Заполняется **на каждый трек** (каталоги «Аурафон», «Джаз Релакс»; только музыка Сергея).

| # | Пункт | Доказательство | Отметка |
|---|---|---|---|
| 1 | Трек: код AL-T-…, `audio_item_id`, название, псевдоним | реестр 01 | [ ] |
| 2 | Сервис генерации и версия модели | скрин страницы генерации | [ ] |
| 3 | **Платный тариф Suno на дату генерации** (Pro/Premier) | чек/инвойс + история подписки с датами | [ ] |
| 4 | ID генерации (song id / URL) и дата генерации | скрин/экспорт из аккаунта | [ ] |
| 5 | **Download proof:** трек скачан из платного аккаунта (обязательно для ToS от 03.09.2026) | скрин истории Download / файл с метаданными / письмо Suno | [ ] |
| 6 | Редакция ToS Suno на дату генерации и на дату скачивания | PDF ToS + SHA-256 файла PDF | [ ] |
| 7 | SHA-256 исходного скачанного файла и файла, загруженного в AudioLad | `sha256sum` | [ ] |
| 8 | **Вклад человека:** текст/лирика, промпт, структура, аранжировка, сведение, мастеринг, отбор вариантов, правки в DAW | описание + проектные файлы/скрины DAW | [ ] |
| 9 | Ремикс/кавер/использование чужого аудио (upload, extend чужого трека)? | да/нет; если да — источник и права | [ ] |
| 10 | Сэмплы и сторонние лупы | список + лицензии | [ ] |
| 11 | Исполнители-люди (вокал, инструменты) | договоры/согласия | [ ] |
| 12 | Итог: CONFIRMED / UNCONFIRMED / WITHHELD; кто проверил, дата | — | [ ] |

**Стоп-условия (трек остаётся WITHHELD):** нет пункта 3 или 5; генерация на бесплатном тарифе; пункт 9 = «да» без прав на источник; расхождение хешей пункта 7 без объяснения.
