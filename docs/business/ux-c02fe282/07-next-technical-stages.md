## План валидации после согласования

Сначала маленькие изменения с собственным diff и smoke. Проверять реальные сигналы под контролируемыми fixtures, без записи в production ради теста. Доступ: anonymous, не allowlisted, allowlisted, отзыв доступа. Звучание/связь: playing, paused, empty, offline, failed read, loading, stale, no_access. Права: UNKNOWN/INELIGIBLE никогда не дают положительной подписи. Контрольные размеры 360/390/1440px и 200% zoom.

Коммит текущей Phase 1 не является разрешением на внедрение, миграции, инфраструктуру или деплой. Следующая сессия начинается с решения Сергея по README checklist, затем отдельного плана конкретных live-изменений.
