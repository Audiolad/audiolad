# Реестр достоверности интерфейса

Классы: **wired-to-real-data** — в коде есть реальный источник; **design-only concept** — вымышленные данные, локальная демонстрация или ещё не подключённая функция. Ни один элемент содержимого нового preview не подключён к реальным бизнес-данным. Существующая оболочка вокруг макета может показывать реальные имя/точку; это явно другой слой.

## Существующий кабинет: реальные подключения и подмены

| Элементы / источник | Класс | Предел |
| --- | --- | --- |
| Имя владельца, org/location/zone в Home, sidebar, onboarding; `domain.ts` | wired-to-real-data | Первая membership/active location; не поддержка сети и не редактор профиля |
| Статус и счётчик плееров, возраст heartbeat/последнего PoP; loaders и `owner-home-signals.ts` | wired-to-real-data | Ошибка health схлопывается в stopped; healthy выводится из online без требования свежего PoP. Формулировки Home шире доказательств |
| Home трек/тайминг/progress, расписание/current, резерв 31/42ч; `mock-data.ts` | design-only concept | Сейчас смешаны с real shell, без постоянного banner |
| Home prev/next/play/pause/like/dislike/skip/atmosphere | design-only concept | Только local state и сообщения; ни одна кнопка не управляет реальным плеером |
| Home «Всё работает», «Музыка играет», «Интернет работает», автономность | design-only concept | Положительные выводы не подтверждают фактическое состояние всей системы; у отдельных компонентов есть реальные health-основания, но этого недостаточно |
| Home «Документы в порядке / Лицензия активна» | design-only concept | Статическая положительная юридическая подпись без источника; приоритет P0 для будущей правки |
| Bootstrap / подтверждение onboarding | wired-to-real-data | Запись org/location/zone через RPC; атмосфера не входит в payload |
| Onboarding атмосфера/описательный preview | design-only concept | Локальный выбор; заявления о сохранении предпочтения и актуальной пустоте всего каталога не подтверждены чтением |
| `/player` создание/назначение, heartbeat, accepted PoP поля | wired-to-real-data | Технический пилот-тон; PoP evidence не подтверждает юридический статус каталога |
| `/music` eligibility rows / счётчик / reason codes | wired-to-real-data | Проверяется фиксированный кандидат; UNKNOWN ≠ ELIGIBLE. Не документ точки |
| `/spa` manifest, названия, текущий track, loading/playing/paused/error/no_access | wired-to-real-data | Локальный online controller + серверный gate/signing. Это не удалённая fleet-сводка и не проверка слышимости колонок |
| `/help` org/location/player/last play/issues | wired-to-real-data | Часть ошибок выглядит как empty; не юридическая проверка |
| `/locations`, `/stats`, `/announcements`, `/documents`, `/team`, `/preferences`, `/more` | design-only concept | Только будущие разделы, без заявленной функциональности |
| Sidebar collapse, текущий пункт / mobile nav | design-only concept | Реальная UI-навигация, но не бизнес-телеметрия; рядом имя/точка из real domain. Заглушки доступны по ссылкам |

Правило будущей реализации: каждое положительное состояние должно иметь конкретный источник, scope точки/устройства и время проверки. Связь, последнее событие, локальная фаза, eligibility трека и документ точки независимы. При неизвестности показывать неизвестность. Не использовать декоративные «играет», «лицензировано», «всё хорошо» в рабочем UI.
