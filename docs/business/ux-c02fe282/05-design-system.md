# Дизайн-система макета

Мягкая фиолетовая / сиреневая система, без оранжевого. Реализация изолирована в `src/components/business-app/design-preview/design-preview.module.css`. Существующие токены оболочки не меняются.

## Палитра и контраст

Числа рассчитаны программно по относительной яркости sRGB: компонента ≤ 0.04045 → c/12.92, иначе ((c+0.055)/1.055)^2.4; L = 0.2126R + 0.7152G + 0.0722B; contrast = (Lmax+0.05)/(Lmin+0.05). Округление до двух знаков. Для обычного текста целевой минимум 4.5:1, для существенных границ контролов / индикатора фокуса 3:1. Расчёт пар не заменяет браузерный a11y-аудит.

| Основной текст | `#2a1a4a` | `#ffffff` | 15.61:1 |
| Основной текст | `#2a1a4a` | `#f7f4fb` | 14.34:1 |

Поверхности: белая `#ffffff`, фон `#f7f4fb`, выделение `#efe7fb`. Обложка — декоративный градиент `#efe7fb` → `#d9c7ef`, не несёт статуса. Disabled controls используют читаемый muted на soft, не снижение opacity. Все ошибки/пауза/связь различаются текстом, а не только цветом; тревожные анимации не используются.

## Типографика, ритм, компоненты

- Системный Arial / Helvetica / sans-serif с кириллицей, без внешней загрузки шрифтов. Body 16px/1.6, вторичный текст 14px, metadata 12–13px. H1 24–32px/1.2, H2 24px/1.3, H3 20px/1.4; веса 400/600, заголовки браузерным bold. Текст без uppercase-полотен.
- Шаг 4px; основной gap 16px, desktop 24px; внутренний padding 16–20px, широкий content 32px. Карточки radius 20px, кнопки 12px, badge 8px. Без тяжёлых теней.
- Primary: одно действие в карточке, solid violet, белый текст. Secondary: белый фон и контрастная граница. Все кнопки/select/summary ≥ 48px по высоте. Focus-visible: 3px accent с offset 3px. Выбранный экран имеет aria-pressed и заливку.
- Будущая функция: статический блок с подписью **«Концепт · позже»**; не кнопка и не ссылка. Выбор экрана концепта разрешён как инструмент просмотра, но не выдаётся за возможность настройки.
- Состояние: badge «Сценарий макета», заголовок с «пример», объяснение и следующий шаг. Нет поддельных timestamps, progress animation, индикаторов здоровья и юридических галочек.

## Адаптивность и доступность

Mobile-first, одна колонка. Рамка телефона max-width 390px, width 100%: сжимается по доступной ширине, включая 360px viewport с padding существующей оболочки. Десктоп — до 1120px, две колонки **по ширине контейнера от 680px**, поэтому телефонная рамка не превращается в desktop при широком окне. Toolbar меняется на три колонки при viewport 760px. Кнопки навигации переносятся, длинный текст переносится, select ограничен шириной.

Нет нового fixed chrome и горизонтальной прокрутки как способа навигации. Внешние sidebar/bottom nav остаются существующими; известный дефект шести пунктов в пяти колонках описан в аудите. Макет не исправляет и не скрывает shell.

Нативные select с видимыми label, button с aria-pressed, details/summary для FAQ; статус `aria-live="polite" aria-atomic="true"`, логичные заголовки h1 → h2 → h3. Декоративные знак/обложка aria-hidden. Нет анимации, autoplay и искусственных задержек. До live-внедрения проверить Tab/Shift+Tab, Enter/Space, масштаб 200%, 360/390/1440px, screen reader и отсутствие перекрытия нижним меню.
