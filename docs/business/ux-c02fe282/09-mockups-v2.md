# 09 · Макеты v2 (/business-app/spa/design-preview)

Только дизайн. Данные — вымышленные; мониторинг, телеметрия и backend не строятся.
Порядок (Сергей + Орий): красивый интерфейс → реальные данные → автоматизация музыки.

## Статусы (поправка Ория, 14.10.2026 09:54 MSK)
Связь с плеером и реальное воспроизведение — разные сигналы. Длинный трек (20–60 мин) никогда не даёт красного.

| Состояние | Заголовок | Цвет |
|---|---|---|
| Плеер на связи, музыка играет | «Музыка играет» | зелёный |
| Плеер на связи, пауза | «Воспроизведение остановлено» | спокойный фиолетовый |
| Нет технического heartbeat 5 мин (не новых треков), рабочие часы | «Нет связи с плеером» | жёлтый (Библия §163) |
| То же, но нерабочие часы | «Точка закрыта» | нейтральный серый, не ошибка |
| Подтверждён сбой воспроизведения | «Музыка не играет» | красный — единственный |

## Экраны
Главная: статус → «Что сейчас играет» (трек, прогресс, программа) → «Что звучало»; справа (на телефоне ниже) музыкальный день, атмосфера, уведомления.
Отдельно: Музыкальный день, Атмосфера («Спокойнее ← ● → Энергичнее», «Больше/Меньше такого»), Лицензия и документы, Уведомления (только когда нужно действие), Мои точки.
Десктоп 1280 и телефон 390, мягкая фиолетовая палитра, статусы читаются не только цветом (иконка + текст). Доступ — тот же гейт, noindex.
