# Матрица принципов, конфликтов и пробелов

Дата исследования: 2026-10-14. Phase 1, c02fe282. Это предложения для согласования, не утверждённая бизнес-архитектура.

## Источники и пределы достоверности

В `docs/business/**` до этой задачи найден только `docs/business/spa-pilot-aurafon-v1.json`. Файл **«Аудиолад Бизнес Библия(4).docx» отсутствует в репозитории** (проверены список файлов и Git). Поэтому ниже нет цитат или вымышленных требований Библии. Сверка с оригиналом остаётся обязательной после его предоставления.

Изучены `AGENTS.md`, `docs/PRODUCT_VISION.md`, все файлы `src/app/business-app/**`, `src/components/business-app/**`, `src/lib/business-app/**`. Аудит основан на коде, без подключения к production и без проверки актуальных прав в БД. JSON пилота — исторический снимок, а не лицензия: в нём прямо сказано о незарегистрированных grants и UNKNOWN на дату снимка.

`PRODUCT_VISION.md` описывает преимущественно аудиопрактики и будущую MAX-воронку; B2B-персоны, тарифы и целевые показатели там не определены. Его утверждения о неподключённом backend нельзя переносить на нынешние Business-модули: здесь уже есть реальные чтения и RPC.
