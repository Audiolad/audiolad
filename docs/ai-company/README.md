# Аудиолад AI Company

Этот каталог — version-controlled операционный контур Аудиолад AI Company.

## Иерархия источников истины

1. Стратегия и решения Сергея / Ория.
2. Product Bible соответствующего продукта.
3. Документы этого каталога.
4. Strategic Goal / Epic.
5. GitHub Issue (Task Packet).
6. PR, handoff и измеренный результат.

Если нижний уровень противоречит верхнему, срабатывает AI Andon: работа останавливается до устранения противоречия.

## Документы

- `OPERATING_MODEL.md` — устройство компании и роли.
- `ORCHESTRATOR.md` — работа Штаба.
- `HUMAN_GATES.md` — границы автономности.
- `RESULT_CONTRACT.md` — контракт результата и handoff.
- `AGENT_GOLDEN_PATH.md` — единый рабочий путь агента.
- `AGENT_PERFORMANCE.md` — оценка и недельное обучение.
- `MARKET_BEFORE_BUILD.md` — Benchmark Before Build.
- `AGENT_ROSTER.md` — первый штат.
- `STRATEGIC_GOALS.md` — действующие цели.
- `DAILY_BRIEF.md` — ежедневная управленческая планёрка.
- `COMMAND_CENTER.md` — визуальный Штаб в админке.

## Основной принцип

Сергей управляет целями, принципами и решениями. Орий — архитектурой и системой. Orchestrator — потоком работы. Агенты создают результаты друг для друга и для пользователя.

Единица успеха — не `Task completed`, а:

`Result delivered → verified → accepted by consumer → used → measured → learned`.
