# Реестр треков и опубликованные аудиофайлы

Ошибка учёта не обнаружена: показатели имеют разный охват.

- **Реестр треков** (`/admin/tracks`): все аудиофайлы музыкальных продуктов
  (альбомы/релизы) с постоянным Track ID, включая неопубликованные и черновики.
- **Опубликованные треки** (главная админки): аудиофайлы со статусом `published`
  в публично доступных продуктах всех типов: музыка, практики/медитации,
  аудиопосты. Каждый файл считается один раз.
- Удалённые продукты исключены из обоих показателей. Аудио практик/медитаций
  и аудиопосты не имеют Track ID по замыслу и не входят в реестр.
- Разбивка реестра использует статус аудиофайла и существующий хелпер
  `practiceAffectsPublicSurface`, соответствующий SQL `practice_affects_public_surface`.
  При поиске разбивка относится только к отфильтрованным строкам.
