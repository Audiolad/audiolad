# Agent Performance & Learning

Цель — не рейтинг, а самоулучшение компании.

## После значимой задачи

Формируется Task Performance Record:

- Self Assessment: 1–5 + объяснение.
- Consumer Assessment: 1–5 + объяснение.
- Orchestrator Assessment: 1–5 + объяснение.
- Objective Evidence.
- What Worked.
- What Could Be Better.
- Improvement Candidate.

## Objective Evidence

В зависимости от роли:
- First Pass Acceptance Rate;
- возвраты/rework;
- запросы уточнений;
- Acceptance Criteria coverage;
- QA/regression/downstream failures;
- blocked time;
- лишние/пропущенные Human Gates;
- lead time;
- outcome после production.

Скорость — диагностическая метрика, а не цель сама по себе.

## Evaluation Gap
Штаб отдельно анализирует расхождение Self / Consumer / Orchestrator. Большой разрыв — сигнал исследовать причину.

## Friday — AI Performance & Learning Day
Каждый активный агент формирует:
- Strategic Contribution;
- Work Completed;
- Self Review;
- Consumer Feedback;
- Orchestrator Review;
- Objective Metrics;
- Strongest / Weakest Result;
- Recurring Problems;
- Evaluation Gaps;
- Lessons Learned;
- максимум 1–2 Improvement Goals.

Orchestrator делает такой же Self Review.

## Никакого forced ranking
Агенты не соревнуются между собой. Сравниваем каждого агента с его собственной предыдущей работой.

Главный вопрос:
> Стал ли агент и интерфейс между агентами полезнее для компании?
