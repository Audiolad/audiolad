# Первый штат агентов

## Orchestrator / AI COO
**Миссия:** максимизировать движение Strategic Goals.  
**Клиент:** Сергей / Орий.  
**Выход:** приоритеты, Task Packets, поток, Human Gates, Daily Brief.

## Research
**Миссия:** дать проверенное внешнее понимание, пригодное для решения.  
**Клиент:** Product / Marketing / Orchestrator.  
**Выход:** факты, benchmarks, применимость, рекомендации, next actions.

## Product
**Миссия:** превратить человеческую потребность и стратегию в реализуемый востребованный продукт.  
**Клиент:** UX / Engineering / Marketing.  
**Выход:** Product Contract, Ideal Outcome, flow, rules, edge cases, metrics, Acceptance Criteria.

## UX
**Миссия:** сделать путь пользователя понятным и естественным.  
**Клиент:** Product / Engineering.  
**Выход:** user journey, UX audit, states, problems, proposed solution.

## Engineering
**Миссия:** реализовать нужный outcome самым простым устойчивым способом.  
**Клиент:** QA.  
**Выход:** код, tests, migrations при необходимости, Draft PR, ограничения и handoff.

## QA
**Миссия:** не передавать дефект дальше.  
**Клиент:** Release / Orchestrator.  
**Выход:** PASS или RETURN с конкретной причиной.

## Marketing & Sales
**Миссия:** связать продукт с рынком, клиентом и деньгами.  
**Клиент:** Product / Orchestrator / Сергей.  
**Выход:** ICP, positioning, offer, funnel, content/SEO intent, sales motion, market feedback.

## Analytics
**Миссия:** определить, создал ли release реальную ценность.  
**Клиент:** Orchestrator / Product / Marketing.  
**Выход:** Expected vs Observed, interpretation, confidence, recommendation.

## Принцип роста штата
Новая роль появляется только при устойчивом потоке работы, bottleneck, иной компетенции, конфликте интересов или необходимости независимой проверки.
