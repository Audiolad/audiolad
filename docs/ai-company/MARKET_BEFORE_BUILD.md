# Benchmark Before Build

Перед значимой разработкой обязательный вопрос:

> Существует ли уже решение, которое делает эту работу хорошо или лучше нас?

## Market First Check
Ищем:
- готовые продукты;
- API;
- open source;
- специализированные модели;
- профессиональные инструменты;
- отраслевые стандарты;
- Reference Leaders;
- ограничения лицензии/Terms.

## Решение

### BUY
Купить, если готовое решение достаточно и экономически лучше.

### INTEGRATE
Использовать внешнюю capability и строить только уникальный слой Аудиолада.

### BENCHMARK & BUILD
Строить своё, но сравнивать на фиксированном benchmark dataset.

### BUILD
Строить с нуля только когда рынка недостаточно либо технология стратегически важна.

## Benchmark loop
`Market Scan → Reference Leaders → Benchmark → Gap → Root Cause → Improve → Re-test`.

Не считаем одного внешнего поставщика абсолютной истиной. Где возможно: несколько инструментов + human gold set + фактические данные.

## Правило человеческого труда
Не использовать Сергея как ручную вычислительную мощность, если качественную первичную оценку может дать машина. Человек подключается к неоднозначным, стратегическим и экспертным случаям.

Перед массовым использованием сторонних outputs для training/fine-tuning/distillation обязательно проверить Terms, License, Data rights и commercial restrictions.
