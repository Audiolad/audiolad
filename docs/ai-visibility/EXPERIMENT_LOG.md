# AI Visibility — журнал экспериментов

Журнал ручных и полуручных проверок видимости АудиоЛада в поисковых и генеративных AI-системах.

**Правила:**

1. Не записывать вымышленные результаты.
2. Одна проверка = одна строка/блок по шаблону ниже.
3. Фиксировать дату, систему, точный запрос и факт (нашли / не нашли / неясно).
4. Не гонять массовые прогоны без необходимости (тариф Cursor / время).
5. Контрольные формулировки брать из [CONTROL_QUERIES.md](./CONTROL_QUERIES.md) или помечать как ad-hoc.
6. Скриншоты/ссылки на ответы — опционально, вне git, если содержат лишнее.

---

## Шаблон записи

```markdown
### YYYY-MM-DD — краткий ярлык

| Поле | Значение |
|------|----------|
| Дата | YYYY-MM-DD |
| Гипотеза | … |
| Система | например: ChatGPT Search / Google AI Overviews / Bing Copilot / Perplexity / Яндекс |
| Запрос | точная формулировка |
| Найден ли АудиоЛад | да / нет / частично / не проверялось |
| Переход или цитата | переход / цитата / упоминание без ссылки / нет |
| Какие источники использовались | URL или «не указано» |
| Результат | кратко, факт |
| Следующий шаг | … |
```
