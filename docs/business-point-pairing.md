# Подключение устройства в зале

Код одноразовый и живёт 20 минут. В базе хранится только SHA-256. Открытый код возвращает функция создания и больше нигде не пишется.

Устройство в зале обменивает код на сеанс. Сеанс тоже хранится как SHA-256. Браузер получает cookie `al-point` только для этого сайта: HttpOnly, без общего домена `.audiolad.ru`. Новый код гасит предыдущий сеанс этой точки. Кнопка «Отключить устройство» делает то же.

Сердцебиение и «сейчас играет» пишет только этот сеанс, функцией `report_business_point_player`. Телефон с обычным входом эти таблицы больше не пишет.

Атмосферу устройство пишет функцией `save_business_point_sound_settings`, и только пока `point_can_edit_settings` включён.

Миграция: `supabase/migrations/20270206120000_business_point_pairing.sql`. На базу её кладёт отдельный выпуск.

Лимит неверных попыток: 5 с одного клиента за 10 минут. После 30 неверных попыток, привязанных к одной кофейне за 20 минут, гасятся только открытые коды этой кофейни – не всех сразу. Миграция: `supabase/migrations/20270223120000_business_point_pairing_no_global_burn.sql`.
