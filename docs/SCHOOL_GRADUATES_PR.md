# Продукты выпускников Школы аудиопрактик

На лендинге school.audiolad.ru сразу после `SchoolTestimonialsScreen` и перед
`SchoolFaqScreen` показывается ручная подборка опубликованных продуктов.
Блок использует ту же оболочку соседних секций Школы: ширину `--school-max`,
фон, скругление и серифный заголовок. Карточки стоят в одной горизонтально
прокручиваемой строке: около одной на мобильном, две на планшете, три на
широком экране. Каждая ведёт на обычную страницу продукта на audiolad.ru.
Комментарии продукта сохраняются.
На каталоге и других публичных страницах платформы блок не рендерится.
Размещение на АудиоЛаде не делается: витрина только на school.audiolad.ru.

В `/admin/school-graduates` Сергей добавляет существующего автора, отмечает
галочку «Выпускник Школы аудиопрактик», выбирает до двух его продуктов и сохраняет.
Новый автор добавляется без галочки и продуктов. Без явной отметки и ручного
выбора ничего не показывается. Каталог исключает черновики, скрытые, удалённые,
будущие публикации и продукты другого автора. Пустая витрина не рендерится.
Имена, названия, обложки и длительности читаются из исходных продуктов.
Если у опубликованного аудио нет длительности дорожек, карточка берёт
`duration_minutes`.

Если выбранный продукт ещё нельзя показать, ошибка сохранения даёт прямую
ссылку на карточку продукта в админке (`/admin/product-moderation/<id>`).
Ошибка загрузки раздела ведёт на ту же страницу `/admin/school-graduates`.

## Миграция и внедрение

Аддитивная миграция `20270130120000_school_graduates.sql` создаёт только новую
таблицу, две функции, trigger, представление `school_graduate_showcase`, права
и RLS. Существующие таблицы и данные не переписываются; автоматического
заполнения нет. `enabled` по умолчанию false хранит ручную отметку выпускника,
два FK хранят явно выбранные продукты.
Миграция никуда не применялась.
**Деплой миграции требует отдельного OK Сергея.**

Публичное чтение идёт только через представление: включённый выпускник и только
те id продуктов, которые сейчас опубликованы и открыты в каталоге. `cohort` и
id снятых или ещё не наступивших продуктов anon не видит. На саму таблицу у
anon и authenticated прав нет.
Публичный `GET /api/school/graduates` возвращает тот же `CatalogCard` DTO, без
кеширования и закрытых аудиоадресов; сам API не рендерит витрину на платформе.
Школьный прокси не открывает платформенные маршруты на school-хосте.

## Проверки

`npm run test:school-graduates` включает модульные проверки и
`supabase/tests/school_graduates.sql` на одноразовой локальной базе.
Production не затрагивался.
