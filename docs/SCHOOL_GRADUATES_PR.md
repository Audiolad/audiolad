# Продукты выпускников Школы аудиопрактик

На лендинге school.audiolad.ru сразу после `SchoolTestimonialsScreen` и перед
`SchoolFaqScreen` показывается ручная подборка опубликованных продуктов.
Карточки расположены в одной горизонтально прокручиваемой строке: около одной
на мобильном, две на планшете, три на широком экране. Каждая ведёт на обычную
страницу продукта на audiolad.ru. Комментарии продукта сохраняются.
На каталоге и других публичных страницах платформы блок не рендерится.

В `/admin/school-graduates` Сергей добавляет существующего автора, отмечает
галочку «Выпускник Школы аудиопрактик», выбирает до двух его продуктов и сохраняет.
Новый автор добавляется без галочки и продуктов. Без явной отметки и ручного
выбора ничего не показывается. Каталог исключает черновики, скрытые, удалённые,
будущие публикации и продукты другого автора. Пустая витрина не рендерится.
Имена, названия, обложки и длительности читаются из исходных продуктов.

Общий серверный компонент `SchoolGraduateShowcase` и представление
`GraduateProducts` остаются переносимыми. Размещение на АудиоЛаде не согласовано;
предложение описано только в REPORT.md рядом с каталогом wt.

## Миграция и внедрение

Аддитивная миграция `20270106120000_school_graduates.sql` создаёт только новую
таблицу, trigger-функцию, trigger, права и RLS. Существующие таблицы и данные
не переписываются; автоматического заполнения нет. `enabled` по умолчанию false
хранит ручную отметку выпускника, два FK хранят явно выбранные продукты.
Миграция при этой доработке не изменялась и никуда не применялась.
**Деплой миграции требует отдельного OK Сергея.**

Публичный `GET /api/school/graduates` возвращает тот же `CatalogCard` DTO, без
кеширования и закрытых аудиоадресов; сам API не рендерит витрину на платформе.
Школьный прокси не открывает платформенные маршруты на school-хосте.
