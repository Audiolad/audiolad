# Чек-лист проверки аудиопродукта

Документ описывает критерии ручной проверки качества и оформления материалов авторов на АудиоЛаде.

Административный интерфейс очереди модерации продуктов пока не реализован. Этот чек-лист предназначен для будущего UI и для текущего ручного процесса.

Новое правило языка применяется ко всем новым продуктам. Существующие опубликованные продукты не снимаются с публикации и не переименовываются автоматически; при существенном редактировании или повторной проверке они постепенно приводятся к стандарту.

Канонический источник формулировок: `src/lib/author-products/language-guidelines.ts` (`PRODUCT_LANGUAGE_MODERATION`, `PRODUCT_LANGUAGE_EXCEPTIONS`, `PRODUCT_LANGUAGE_DISPUTE_NOTE`).

---

## Обязательная обложка

Продукт нельзя отправить или повторно отправить на модерацию без загруженной обложки. Авторский интерфейс показывает ошибку «Загрузите обложку.», а серверный маршрут отправки на модерацию отклоняет запрос с кодом `missing_cover`.

Это технический обязательный минимум для модерации. Декоративная системная заглушка на публичной карточке не считается обложкой продукта.

Проверка закреплена на уровне формы автора, серверного маршрута отправки и SQL readiness, поэтому отсутствие обложки нельзя обойти прямым вызовом API/RPC.

---

## Язык и оформление

Модератор проверяет пункты из `PRODUCT_LANGUAGE_MODERATION.checks`:

- название преимущественно на русском языке
- подзаголовок и описание понятны русскоязычной аудитории
- отсутствуют необоснованные англоязычные названия и выражения
- основные надписи на обложке выполнены кириллицей
- иностранные слова используются обоснованно
- название на странице соответствует названию на обложке

### Допустимые исключения

См. `PRODUCT_LANGUAGE_EXCEPTIONS` и `PRODUCT_LANGUAGE_DISPUTE_NOTE`.

### Решение при нарушении

Нарушение этого правила **не ведёт к окончательному отклонению** продукта.

Решение модератора: **Требуются изменения** (`PRODUCT_LANGUAGE_MODERATION.outcomeLabel`)

Пример комментария автору (`PRODUCT_LANGUAGE_MODERATION.sampleComment`):

> Пожалуйста, замените англоязычное название продукта и текст на обложке понятным русским вариантом. Иностранное название при необходимости можно указать дополнительно после русского.

### Важно

Не блокировать продукт автоматически только из‑за наличия латинских символов: допустимы псевдонимы, бренды, технические обозначения (MP3, PDF и т.п.), иностранные произведения и языковые материалы. Окончательное решение принимает модератор с учётом контекста.

Справка для авторов: `/help/authors/language-and-formatting`.
